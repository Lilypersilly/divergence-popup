# Wayland Divergence Meter Popup
A native GTK/Rust popup for Wayland/Hyprland that mimics the Divergence Meter from Steins;Gate.

## Assets Required
To respect the original artist's copyright, this repository does not include the Nixie tube image files. 

To use this widget:
1. Create a folder at `~/.config/waybar/nixie-assets/`
2. Place your Nixie tube images inside, named `0.png` through `9.png` and `dot.png`. As well as SE.wav for an on-run sound effect.
